第 2 章 · Skills 是什么（3 分钟版，含机制）

Skill = 一个带说明书的工具文件夹。SKILL.md 分两部分：

· frontmatter（机器读）：name + description。Claude 不加载正文，它读每个 skill 的 description 来决定「此刻要不要用这个技能」。
· 正文（工作时读）：工作流、输出格式、反模式。

这意味着一个关键事实：description 是触发面，不是文档。写得含糊（「帮助提升代码质量」）的 skill 永远沉睡；写得精确（「MUST USE when the user asks to review a PR / 审查这次改动 / 这个能上线吗」）的 skill 每次都命中。

三种老办法为什么不如 skill：

老办法问题Skill 怎么解决
每次打字交代重复几十遍，版本漂移写一次，永久生效
写进 CLAUDE.md常驻上下文，占 token，互相干扰按需加载
MCP 工具给的是能力（新手动做）Skill 给的是方法（新脑）
一句话：Skills 把「你每次都要重复交代的老练做法」固化成了资产。
